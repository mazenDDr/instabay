# افتتاحية عربية مرتبطة بالدليل — FR-04

أعد JSON مطابقاً لمخطط GroundedCaptionDraft فقط. اكتب بفصحى بسيطة وطبيعية، من الموجز
والدليل المرئي وهدف الركيزة. هذا مرجع تاريخي لمنتجع في المالديف، وليس مرافق إنستا باي.

opening: فكرة واضحة ومحددة في ٤–١٢ كلمة تربط المشهد بهذه الركيزة. فضّل جملة مباشرة
على سؤال عام. لا تكرر previous_openings ولا تعِد صياغتها، ولا تنسخ افتتاحية الموجز.
لا تجعل الماء يسأل أو الشاطئ يتنفس، ولا تكتب «جنة على الأرض» أو «تجربة لا تنسى».
ركيزة الماء تلفت الانتباه للعلاقة المرئية بين الماء والشاطئ؛ الاسترخاء للمساحة أو
الظل؛ الإقامة للممر أو المباني الظاهرة؛ المكان لتفصيل واضح وموقع المالديف الصحيح؛
التخطيط لمقارنة الإطلالات قبل اختيار الوجهة. لا تضف حقيقة غير موجودة في الدليل.

action: طلب إجراء واحد صريح يوافق selection.cta_kind: الحفظ أو مقارنة الإطلالات أو
ذكر تفضيل محدد في تعليق أو التنقل بين صور المنشور. نوّع الصياغة. لا تعد بعرض أو سعر
أو غرفة أو توافر حجز. اختر fact_id من visual_context.facts فقط. سيضيف البرنامج
التفاصيل الواقعية والنص البديل من عبارات الدليل العربي؛ اجعل detail وalt_text فارغين.

لا تختلق مسابح أو سبا أو غرفاً أو أنشطة أو قصص ضيوف أو كائنات بحرية. لا تصف وقتاً
أو أصواتاً أو روائح أو حرارة الماء أو حالة راهنة لا تثبتها الصور. لا تنسب المكان
إلى الغردقة أو البحر الأحمر، ولا توحِ بالملكية أو الشراكة. لا تضف وسوماً أو لغة تدقيق
أو مصطلحات تقنية أو رموزاً تعبيرية. لا تتلقَّ تعليقاً إنجليزياً ولا تترجمه.
