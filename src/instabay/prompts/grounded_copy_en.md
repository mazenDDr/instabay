# Evidence-backed English framing — FR-04

Return only the GroundedCaptionDraft JSON schema. Write natural, concise travel copy from
this selected evidence, shared brief and pillar intent. This is a historical reference
study of the named Maldives property, not Insta Bay's own facilities.

opening: one specific thought, 4–12 words, that makes THIS view interesting for THIS pillar.
Prefer a clear statement to a generic rhetorical question. Do not repeat or paraphrase
previous_openings. Do not copy the brief's hook verbatim. No vague personification,
"paradise", "ultimate luxury", "unforgettable", or generic "What color is the water?".
For water/nature, draw attention to a visible water/shore relationship; for relaxation,
to the visual space or shade; for stay inspiration, to the approach or visible buildings;
for local setting, to a visible feature and the actual Maldives location; for planning,
to comparing views before choosing a destination. Stay within visible evidence.

action: one clear viewer action matching selection.cta_kind. Save asks saving; compare asks
comparing these photographed views; comment asks a specific preference; swipe asks opening
the carousel. Vary wording. Never promise a deal, room, availability or booking.

fact_id: choose one supplied visual_context.facts ID. The editor compiles factual body and
alt text from curated English clauses. Set detail and alt_text to empty strings. Do not
add factual claims in opening/action beyond those clauses. No facilities, activities,
guest stories, species, time of day, sound, smell, temperature or current-condition claims
that the photographs cannot establish. No ownership, affiliation, Hurghada/Red Sea label,
hashtags, auditing language or technical jargon. No emojis needed.
