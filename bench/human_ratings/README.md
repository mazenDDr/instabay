# HUMAN ratings

Completed `brand_*.csv`, `arabic_*.csv` and `approval_*.csv` files go here and are git-ignored.
No human ratings are supplied or fabricated. Run `make bench` to prepare the blinded packet
and schema-valid blank templates in `outputs/bench/human_packet/`.

Use [the protocol](../README.md) and [rubric](../rubric.md). Returned ratings are checked for
complete score rows, valid bounds, duplicate rater/item pairs and exact caption signatures.
Approval feedback here is benchmark data only and cannot authorize application publishing.
