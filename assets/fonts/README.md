# Arabic overlay font

Noto Naskh Arabic variable font, downloaded from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notonaskharabic).
The unmodified font is distributed under the included SIL Open Font License (`OFL.txt`).
Every recipe stores its exact SHA-256. Arabic is reshaped and put into visual RTL order before
painting overlays; text is never requested from a video model.

The brief-led editor also includes unmodified variable fonts
[Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) (`OFL-Manrope.txt`) and
[Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic)
(`OFL-NotoSansArabic.txt`), both under the SIL Open Font License.
Manrope supplies the English edition and Noto Sans Arabic the Arabic edition.
Their exact bytes are hashed into each directed recipe.
