# Arabic overlay font

Noto Naskh Arabic variable font, downloaded from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notonaskharabic).
The unmodified font is distributed under the included SIL Open Font License (`OFL.txt`).
Every recipe stores its exact SHA-256. Arabic is reshaped and put into visual RTL order before
painting overlays; text is never requested from a video model.
