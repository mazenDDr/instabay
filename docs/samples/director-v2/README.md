# Directed resort preview — v2

Watch the [English MP4](preview-en.mp4) or [Arabic MP4](preview-ar.mp4).
[English contact sheet](contact-en.jpg) · [Arabic contact sheet](contact-ar.jpg).

This is an 18-second mixed-media preview using historical photographs of The Grand Resort,
Hurghada. Local Qwen generated the creative board; two separate native Wan clips animate
flowers and photographed water. Six other shots use camera edits of real photographs.
Text is sparse, white and unboxed. Each language has its own export and an original
procedural soundtrack. It is reference-only, contains AI-generated scenes, and is not
approved for publication. It does not demonstrate current resort facilities or endorsement.

See [creative measurements](creative-en.json), [actual generation audit](generation.json),
[raw native board](board.native-raw.json), [reviewed board](board.reviewed.json) and
[editorial changes](editorial-review.json). The audit includes failed attempts; model output
was not accepted unchanged. The saved invalid response illustrates the earlier format/timing
failure. The reviewed Arabic hook corrects awkward wording, and static camera directions
become photographic moves. Source media and crop approvals were bound from the catalog,
never generated by the LLM. There is no measured retention gain or automated appeal verdict.

[English recipe](recipe-en.json) and [Arabic recipe](recipe-ar.json) bind the brief-led board,
source clips, derived reference crops, exact font bytes and actual score. Motion subfolders
preserve original GPU recipes and results. Native recipe paths describe the GPU run; the
compiled CPU recipes reference files committed in this repository. Result summaries retain
original local render paths as audit evidence; per-frame hashes live in separate manifests.
Use the linked MP4 copies to view the exports.

To reassemble without a GPU, use the recorded catalog and create a recipe with the
current local FFmpeg/runtime identity:

```sh
uv run instabay direct-video --brief docs/samples/director-v2/brief.json \
  --board docs/samples/director-v2/board.reviewed.json \
  --catalog docs/samples/director-v2/catalog.yaml --render
```

Recreating a recipe for the current runtime is necessary: original recipes intentionally reject a different
FFmpeg binary or implementation hash. The source clips are already stored locally; no
native generation is required for this assembly.

Full source authors, licenses, modifications and disclosure lines are in
[English caption metadata](caption-en.json) and [Arabic caption metadata](caption-ar.json).
Photographs and fonts retain their original licenses. Motion intervals are chosen internally;
no manual first/last-frame decisions are required. Human fidelity and appeal review remain
pending. All technical checks can pass while an edit still needs creative improvement.
