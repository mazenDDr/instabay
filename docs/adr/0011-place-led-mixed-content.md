# 0011 — Let source evidence and the editor constrain the creative model

Status: implemented; human preference and publication approval pending.

The previous detail-led edit could satisfy media specifications while failing the user's request to experience a place. Use a separate scenic mode: three to five distinct, complete scenes, four to seven seconds per shot, physical footage throughout, and no opening or body panels. The reference-week editor removes model overlays entirely and assigns opening/closing roles; raw responses remain in the audit. The model chooses scene order and narrative purpose, while deterministic code owns timing, factual joins and legibility. Keep legacy recipes and defaults compatible. Configure separate photo/carousel/reel floors without changing the frozen Insta Bay constitution. Build actual feed images and ordered carousels, not just text describing them. Bind factual EN/AR body clauses and alt text to observed, localized source facts; independently generated openings and actions still need human review. A larger local writer improved one paired viewpoint error but retained an absurd spatial description, so model size alone is not evidence of factual quality. Store source scope, recipes, hashes and human-pending reviews, and block reference media from live publishing. Full-frame motion differences remain diagnostic, never a beauty or engagement score.

Linux replay exposed FFmpeg-dependent JPEG conditioning bytes. Recorded replay now retains the original conditioning images and verifies their native hashes, while explicitly generating a new CPU runtime recipe. Regenerating a crop is not allowed to silently change which photograph conditioned a generated clip. The network-disabled Linux replay passes media specifications; cross-runtime byte identity is not claimed.
