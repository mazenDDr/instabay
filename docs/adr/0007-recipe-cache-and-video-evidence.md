# ADR 0007: verified render cache and honest video evidence

Use exact stored recipes and verified artifact hashes as the L0 guarantee. A CPU Ken Burns backend
provides the offline gate over an explicitly synthetic still; resort originals remain unapproved.
Record local preview recipe/byte hashes in the post snapshot before human approval. Arabic is
reshaped/bidi ordered and painted into overlays with a pinned OFL font and BASIC layout, avoiding
platform-dependent double shaping. Native adapters are opt-in and local-weight only; unsupported
FLF/LoRAs, absent pins and incomplete native jobs fail instead of silently falling back. A private
SQLite worker serializes jobs and preserves uncertainty for reconciliation. Actual media spec
checks are automatic; missing DINO/vision/property evidence flags the reel for review. CPU frame
replay is measured without cache reuse; GPU/cross-machine/paid quality, Qwen keyframe generation,
RIFE/upscalers and C2PA remain human spike or stretch work. This keeps the phase offline gate
meaningful without presenting synthetic tests as native model measurements.
